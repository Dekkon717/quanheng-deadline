# 法律规则与法源

当前规则库共100项，分为普通诉讼时效、特别诉讼时效、仲裁时效、除斥与权利行使期、担保与优先权、诉讼与执行期限、不适用诉讼时效、刑事追诉期限、行政起诉期限、行政复议申请期限十类。其中79项在法定起算事实明确时可以自动生成基础参考日期，其余规则进入人工判断边界。

系统中每一项规则均包含：规则编号、权利或案件类型、期限性质、具体条文、法定起算说明、自动化等级、适用风险和官方原文链接。完整机器可读规则位于 [`lib/deadline-catalog.ts`](../lib/deadline-catalog.ts)。

主要官方法源包括：

- 《中华人民共和国民法典》及总则编司法解释、时间效力规定；
- 诉讼时效制度司法解释；
- 劳动争议调解仲裁法、农村土地承包经营纠纷调解仲裁法、仲裁法；
- 保险法、产品质量法、专利法及知识产权司法解释；
- 生态环境法典及其时间效力规定；
- 2025年修订海商法、民用航空法；
- 票据法、信托法、公司法；
- 建设工程、担保制度、建筑物区分所有权司法解释；
- 民事诉讼法及其司法解释。
- 《中华人民共和国刑法》（2023年修正）第87—89条；
- 《中华人民共和国行政诉讼法》、行政诉讼法司法解释，以及2026年5月1日起施行的《最高人民法院关于适用行政诉讼起诉期限若干问题的解释》；
- 《中华人民共和国行政复议法》（2023年修订）。

每份官方法源的效力状态、施行日期、核验日期和链接均保存在规则数据中，并在网页版结果页面展示。

## 刑事与行政期限的术语边界

- 刑事规则称为“追诉期限”。系统只依据具体罪名所适用法定刑幅度的法定最高刑分档，不以预计量刑或宣告刑代替。
- 行政诉讼规则称为“起诉期限”。直接起诉、复议后起诉、不履行法定职责和行政上诉分别处理。
- 行政复议规则称为“行政复议申请期限”，并同时核对六十日一般期间、一年特殊节点以及五年／二十年最长受理期限。
- 连续或继续犯罪、追诉期限内再犯罪、刑法第88条例外、核准追诉、行政期限扣除或延长、错误告知、复议前置等复杂情形不机械计算。

## 更新纪律

1. 先取得国家机关公开的现行法律文件。
2. 核验效力、施行日期和新旧法衔接。
3. 将条文构成要件拆成起算点、期间、最长期间和风险门控。
4. 增加边界测试后才能进入自动计算。
5. 无明确法条或事实存在重大争议时，只能标记为人工判断。
