# 法律规则与法源

当前规则库共75项，分为普通诉讼时效、特别诉讼时效、仲裁时效、除斥与权利行使期、担保与优先权、诉讼与执行期限、不适用诉讼时效七类。

系统中每一项规则均包含：规则编号、权利或案件类型、期限性质、具体条文、法定起算说明、自动化等级、适用风险和官方原文链接。完整机器可读规则位于 [`lib/deadline-catalog.ts`](../lib/deadline-catalog.ts)。

主要官方法源包括：

- 《中华人民共和国民法典》及总则编司法解释、时间效力规定；
- 诉讼时效制度司法解释；
- 劳动争议调解仲裁法、农村土地承包经营纠纷调解仲裁法、仲裁法；
- 保险法、产品质量法、专利法及知识产权司法解释；
- 生态环境法典及其时间效力规定；
- 2025年修订海商法、民用航空法；
- 票据法、信托法、公司法；
- 建设工程、担保制度、建筑物区分所有权司法解释；
- 民事诉讼法及其司法解释。

每份官方法源的效力状态、施行日期、核验日期和链接均保存在规则数据中，并在网页版和小程序结果页面展示。

## 更新纪律

1. 先取得国家机关公开的现行法律文件。
2. 核验效力、施行日期和新旧法衔接。
3. 将条文构成要件拆成起算点、期间、最长期间和风险门控。
4. 增加边界测试后才能进入自动计算。
5. 无明确法条或事实存在重大争议时，只能标记为人工判断。
